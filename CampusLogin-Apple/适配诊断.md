# 苹果端适配诊断与验证记录

## 原项目结论

当前仓库已有 Windows Electron 1.0.5 客户端和 Android Java 客户端。`CampusLogin/src/main/portal.js` 的认证引擎是有序 GET / JSONP 请求；`capture.js` 保存接口模板；`discovery.js` 的路由和 SSID 读取依赖 Windows 命令。Android 的 `LoginService`、`BootReceiver` 不能直接用于 iOS。单纯增加 Electron 打包参数无法得到 iOS 客户端，也无法保证原网络发现和浏览器向导在 macOS 上正常工作。

新增独立 SwiftUI 工程，共用原项目的协议规则，不修改现有 Windows、Android 实现。两端使用系统 URLSession、Network、Security；macOS 另使用 ServiceManagement 管理登录项。

## 本地验证

在 Windows 上执行了工程结构检查：两端源文件引用、构建配置、共享 schemes、权限 XML、隐私声明资源、图标尺寸及不透明 RGB 格式均通过。生成脚本和校验脚本通过 Node 语法检查。`git diff --check` 通过。

无法在本机执行 Swift/Xcode 编译。新增 `apple-build.yml`，在 macOS 上运行 `swift test`，然后编译 iOS 模拟器和 macOS 应用；本次未推送代码或运行 GitHub Actions，因此这些检查仍为待验证状态。

## Mac / 真机验收清单

1. 执行 `bash CampusLogin-Apple/scripts/build-apple.sh`，确认协议测试与两端编译通过。
2. 在非校园网络、拒绝本地网络权限、错误门户地址下点击“仅检查”，确认没有账号密码请求。
3. 在校园 Wi-Fi 下验证仅检查、正确登录和本人注销；确认注销后不会立即自动登录。
4. 验证同账号已在线时不重复登录，其他账号在线时不登录、不注销。
5. 验证密码拒绝立即停止、三次失败停止、暂停期间网络恢复不会绕过停止状态。
6. 在 iPhone 上锁屏、切后台、回前台；确认前台恢复规则、权限提示及学到的运营商后缀。
7. 在 Mac 上关闭面板，从菜单栏重新打开；安装签名应用后验证系统登录项及有线网络。
8. 验证密码未出现在 UserDefaults、导入文件、日志或崩溃描述中；验证导入真实 Windows 档案。

只有完成 Mac 编译和校园网真机验收后，才能把该工程标记为可发布版本。
